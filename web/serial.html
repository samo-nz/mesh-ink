GPS power-test workflow

      
    
        
  1. Run the GPS power experiment with USB disconnected so charging does not contaminate the current measurement.
    2. 
        
  2. After the test finishes, reconnect USB and open this Serial Monitor.
    3. 
        
  3. On the T5 choose GPS Power Saving → Replay Last Log.
    4. 
        
  4. Press Copy all here, then paste the result into ChatGPT.
    5. 
      

      
If the T5 resets and its USB serial port disappears, wait for it to return and press Reconnect. Reconnect reuses the previously authorized T5 without opening the device picker; use Connect only if permission has been lost. The existing log remains untouched. Flashing and serial monitoring cannot use the same USB port at the same time.

    


    

      
Browser support

      
Use Chrome or Edge on desktop, or Chrome on Android. Android uses the same WebUSB serial compatibility layer as the MeshInk web flasher. USB serial access requires a secure HTTPS page and your explicit device selection.
