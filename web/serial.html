Using the console

      
Connect selects or opens a USB serial device. Disconnect closes it while keeping the captured log. Reconnect tries to reopen the previously authorized device without opening the device picker.

      
The console prioritizes USB capture over screen rendering: incoming chunks are retained immediately, while the visible terminal is updated in batches. For very long sessions only the recent visible tail is rendered; Copy all still uses the complete captured log.

      
If a device resets, its USB port may disappear for several seconds. Wait for it to re-enumerate, then press Reconnect. If the browser no longer exposes the previous authorization, use Connect to select it again.

    


    

      
Browser support

      
Use Chrome or Edge on desktop, or Chrome on Android. Android always uses the WebUSB serial compatibility layer; desktop browsers use native Web Serial when available. USB access requires HTTPS and explicit device permission.
