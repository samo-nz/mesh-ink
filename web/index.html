Before connecting

  1. Use desktop Chrome or Edge on a computer with Web Serial support. Close PlatformIO Serial Monitor and any other app using the board's USB port.
  2. Connect the T5 with a data-capable USB cable. Choose the T5 USB serial port when prompted.
  3. If the flasher cannot connect, hold BOOT, briefly press RESET, then release BOOT and try again.
  4. Keep USB connected until flashing completes. Press RESET if the board does not restart automatically.

Update is intended for boards already running MeshInk with its existing partition layout. For a blank board or a different firmware/partition layout, choose Fresh installation, which erases stored data.
