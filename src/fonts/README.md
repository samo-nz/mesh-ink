MeshInk primary UI fonts
========================

The built-in smooth UI glyph data in this directory is generated from Inter.
The three raster sizes are deliberately 1-bit (black/white), not grayscale,
so the normal e-paper Direct/DU refresh path remains monochrome.

Inter is licensed under the SIL Open Font License 1.1. See INTER_LICENSE.txt.
The generated font headers were sourced from the public CrumBLE firmware tree,
which generates its Inter assets with FreeType at the T5/EPDiy target density.
