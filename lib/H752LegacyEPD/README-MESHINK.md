# H752 legacy EPD driver

This directory contains the LILYGO ED047TC1 driver used by the original H752
revision of the T5 E-Paper S3 Pro. It is vendored from the official
`Xinyuan-LilyGO/T5S3-4.7-e-paper-PRO` repository, branch `H752`.

MeshInk keeps this driver isolated from the H752-01/EPDiy v7 path. It is used
only by the experimental original-H752 build and has not been physically
validated by the MeshInk maintainer.
